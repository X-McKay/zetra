# T24 lifecycle qualification

Parent-approved scope: add a signed `tenant-test/conformance-lifecycle` fixture,
a read-only harness, and an isolated same-image worker on a run-specific queue.
Keep the production SessionWorkflow, retry policies, eight-hour business deadline,
confirmed deletion and reconciler schedule unchanged.

1. Add an opt-in APS observer authenticated by TokenReview for the exact
   conformance-harness SA and APS audience. Bind observations to trusted stored
   tenant-test/conformance-lifecycle ownership. Report actual grant-record and
   vault presence/remaining TTL, generation, stopped and cleanup-pending only.
   Preserve bounded owner metadata after discovery removes a fully cleaned row.
2. Add strict lifecycle control/config and evaluator tests. Root creates the
   exact control ConfigMap and writes commands; harness and worker only read.
   Genuine activity heartbeats expose waiting gates. Unknown/missing/replaced
   controls, observations, histories, Pods or operator receipts fail closed.
3. Add an isolated worker wrapping real activities at deterministic gates and a
   deterministic signed fixture. It must run actual operations and preserve
   normal SDK/image validation. No synthetic Temporal results, fake grants or
   production fault injection.
4. Prove the four exact 15.2 faults: APS unavailable during cleanup; exact Pod
   finalizer preventing deletion; exact isolated worker killed mid-cleanup; and
   Temporal hard termination. Root performs all Kubernetes faults/restoration.
   Each starts from a genuine grant and vault with >600s remaining TTL and an
   active generation, and independently proves all session Pods gone, generation
   absent, actual grant record absent, vault absent and no pending stop <=600s.
   Successful stop must not be blocked by a failing Pod deletion, and a failed
   stop must not prevent confirmed Pod deletion.
5. Include healthy completion/cancellation, real activity loss and retry
   exhaustion as supplemental cases. An accelerated timer, if used, is explicit
   isolated-worker supplemental evidence only, never eight-hour qualification.
6. Run focused red/green regressions, all APS tests/vet, runner tests/Ruff and
   fixture checks; obtain independent review before PRs. Live genuine grants
   require parent-managed authorization and are not fabricated by unit tests.

Observer reads may lazily expire store entries by ordinary TTL semantics. They
never reset ledgers, stop sessions, delete grants, reveal handles/credentials or
mutate authorization. Four-fault live qualification remains pending until a raw
report establishes the evidence; local tests alone do not establish T24.
